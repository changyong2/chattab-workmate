# WORKMATE 팀미팅 에디션

총 40문항을 5페이지에 섞어 보여주는 채팅탭 팀미팅 설문입니다.

- 업무 성향 24문항: 8개 관점별 3문항. 직군은 예시에만 사용합니다.
- 팀 업무·생활 12문항: 만족도, 유지할 방식, 회고 실행, 공통 기준, 생활 룰 유지·변경, 변화 부담, 새 제도와 서술 의견을 받습니다. 생활 룰 1문항에는 7개 항목이 있습니다.
- 밸런스 게임 4문항: 문서/화이트보드, 회의 타이머/자동 회의록, 혼자 충전/함께 외출, 미래 문제 예측/반복 업무 자동화. 개인의 재미 별명과 메이트의 보너스 취향 비교에 사용하며 업무 궁합 점수에는 넣지 않습니다.

## 결과와 링크

- 참가자 설문: `index.html#survey`
- 관리자 코드 취합: `host.html#host`
- 나의 업무 성향·스타일·채팅탭 궁합: `mate-results.html#profile`
- 메이트 공개·궁합률: `mate-results.html#results`
- 팀 업무·생활 종합 의견: `work-life-results.html`
- 데이터 없이 미리보기: `mate-results.html?sample=1#profile`, `mate-results.html?sample=1#results`, `work-life-results.html?sample=1`

모든 결과는 문장 요약부터 보여줍니다. 업무 캐릭터 별명은 재미를 위해 과장한 표현입니다. 메이트 궁합률은 협업 리듬 유사도 85%와 역할 대비 15%의 합입니다. 채팅탭 궁합은 본인을 제외한 실제 참가자 평균과의 협업 리듬 유사도이며, 다른 참가자가 없으면 표시하지 않습니다. 점수는 이번 응답을 비교하는 값이며 관계·성과 예측이나 채용·인사 평가가 아닙니다. 동점은 함께 표시합니다.

## 수집 및 버전

참가자는 메이트·밸런스 게임의 WM6 코드와 팀 의견의 WL2 코드를 각각 주최자에게 전달합니다. WL2는 닉네임·직군 없이 별도 무작위 ID로 만듭니다. 전달 경로나 서술 내용으로 작성자를 알아볼 수 있어 익명성을 보장하지 않습니다. 코드는 암호화되지 않았으므로 공개하지 않습니다.

기존 64문항 데이터와 새 40문항은 섞지 않습니다. 이전 브라우저 저장 키는 지우지 않고 그대로 두며, 새 버전은 별도 저장 공간을 사용합니다. WM5·WL1은 새 관리자에서 받지 않습니다. WM6·WL2를 새로 모아주세요.

응답과 취합은 현재 브라우저에만 저장되며 서버로 자동 전송하지 않습니다. 관리자 링크 분리는 로그인 인증을 제공하지 않습니다. 같은 WL2 응답 ID를 다시 등록하면 이전 답변을 갱신합니다. 실제 응답과 백업은 저장소에 넣지 않습니다.

## 실행 및 검증

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory dist
node test-model.cjs
node test-insights.cjs
node test-work-life.cjs
node test-personal-profile.cjs
node test-result-stories.cjs
node test-meeting-flow.cjs
```

`main`은 소스·검증을, `gh-pages`는 `dist` 배포본을 보관합니다.
