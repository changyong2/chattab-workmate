# WORKMATE

협업 방식을 돌아보는 워크숍 웹 앱입니다. 서로 다른 행동 선택지 4개로 구성한 48문항을 사용합니다.

- 직군: 개발, 디자인, PO/PM. 질문 예시를 바꾸는 데만 사용하며 매칭 점수에는 포함하지 않습니다.
- 참가자는 설문을 완료한 후 생성된 응답 코드를 주최자에게 전달합니다.
- 주최자는 별도 페이지에서 코드를 모아 결과를 공개합니다.
- 서버와 데이터베이스가 없는 정적 웹 앱입니다. 입력한 응답과 취합 목록은 현재 브라우저에 저장됩니다.
- 응답 코드는 이름·직군·답변을 포함하며 암호화된 비밀 토큰이 아닙니다. 코드 자체를 공개하지 마세요.
- 주최자 페이지의 링크 분리는 로그인 인증을 제공하지 않습니다.

매칭은 워크숍 대화를 위한 참고용이며, 검증된 심리검사나 업무 성과 예측이 아닙니다.

## 실행 및 확인

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
node test-model.cjs
```

`main` 브랜치에는 원본과 모델 검증을, `gh-pages` 브랜치에는 `dist`의 정적 배포 파일을 보관합니다. 실제 참가자의 응답 데이터나 취합 백업은 저장소에 포함하지 않습니다.
