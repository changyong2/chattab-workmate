# WORKMATE 팀미팅 에디션

총 40문항을 5페이지에 섞어 보여주는 채팅탭 팀미팅 설문입니다.

- 업무 성향 24문항: 8개 관점별 3문항. 질문에 상황과 선택 대상을 직접 적고, 모든 직군에 같은 질문·답변을 사용합니다.
- 팀 업무·생활 12문항: 회의·협의 진행의 편안함, 유지할 습관, 의견·도움 요청의 팀 온도, 새 팀을 꾸릴 때의 공통규칙, 회식·점심 등 생활 운영의 유지·변경과 서술 의견을 받습니다. 생활 룰 1문항에는 7개 항목이 있습니다.
- 밸런스 게임 4문항: 문서로 정리/그림으로 설명하는 개인 초능력, 내 할 일 즉시 완료/내가 찾는 결정 즉시 검색, 혼자 충전/동료와 카페, 복잡한 일을 함께 풀어주는 동료/어려운 얘기도 편하게 나누는 동료. 개인의 재미 별명과 메이트의 보너스 취향 비교에 사용하며 업무 궁합 점수에는 넣지 않습니다.

## 결과와 링크

- 참가자 설문: `index.html#survey`
- 관리자 코드 취합: `host.html#host`
- 나의 업무 성향·스타일·채팅탭 궁합: `mate-results.html#profile`
- 메이트 공개·궁합률: `mate-results.html#results`
- 팀 업무·생활 종합 의견: `work-life-results.html`
- 데이터 없이 미리보기: `mate-results.html?sample=1#profile`, `mate-results.html?sample=1#results`, `work-life-results.html?sample=1`

모든 결과는 문장 요약부터 보여줍니다. 업무 캐릭터 별명은 재미를 위해 과장한 표현입니다. 메이트 궁합률은 협업 리듬 유사도 85%와 역할 대비 15%의 합입니다. 채팅탭 궁합은 본인을 제외한 실제 참가자 평균과의 협업 리듬 유사도이며, 다른 참가자가 없으면 표시하지 않습니다. 점수는 이번 응답을 비교하는 값이며 관계·성과 예측이나 채용·인사 평가가 아닙니다. 동점은 함께 표시합니다.

## 수집 및 버전

참가자는 메이트·밸런스 게임의 WM8 코드와 팀 의견의 WL3 코드를 각각 주최자에게 전달합니다. WL3는 닉네임·직군 없이 별도 무작위 ID로 만듭니다. 전달 경로나 서술 내용으로 작성자를 알아볼 수 있어 익명성을 보장하지 않습니다. 코드는 암호화되지 않았으므로 공개하지 않습니다.

이전 질문 버전과 전면 수정한 이번 40문항은 섞지 않습니다. 이전 브라우저 저장 키는 지우지 않고 그대로 두며, 새 버전은 별도 저장 공간을 사용합니다. 이전 WM5·WM6 및 WL1·WL2는 새 관리자에서 받지 않습니다. WM8·WL3를 새로 모아주세요.

응답과 취합은 현재 브라우저에만 저장되며 서버로 자동 전송하지 않습니다. 관리자 링크 분리는 로그인 인증을 제공하지 않습니다. 같은 WL3 응답 ID를 다시 등록하면 이전 답변을 갱신합니다. 실제 응답과 백업은 저장소에 넣지 않습니다.

## 실행 및 검증

```sh
python3 -m http.server 8766 --bind 127.0.0.1 --directory dist
node test-model.cjs
node test-insights.cjs
node test-work-life.cjs
node test-personal-profile.cjs
node test-result-stories.cjs
node test-meeting-flow.cjs
node test-team-temperature.cjs
```

`main`은 소스·검증을, `gh-pages`는 `dist` 배포본을 보관합니다.

팀 온도는 의견을 말하고 도움을 청하기 편한 정도의 5개 응답을 10·30·50·70·90°C로 환산한 평균입니다. 판단 보류는 평균에서 제외하고 인원과 분포를 함께 표시합니다. 새 팀을 꾸릴 때의 규칙 선호를 현재 팀의 문제나 개선 요구로 해석하지 않습니다.

40번을 수정하기 전의 개인 임시 응답은 1~39번을 보존해 새 초안으로 옮기고 40번만 다시 고르게 합니다. 구버전 메이트 취합 목록은 별도 보관합니다.
